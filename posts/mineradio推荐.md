# MineRadio：把听歌变成私人演唱会的免费开源音乐播放器

前两天刷 B 站，被一个视频的封面镇住了——背景是星空森林，正中间浮着几行大字「一样的月光」，底下是密密实实的频谱方块在往上涌。我以为是个 MV，结果点进去发现是个**音乐播放器**。

这就是 MineRadio，作者 XxHuberrr，定位叫「Private Visual Radio 私人视觉电台」。

![MineRadio 启动界面：Mineradio logo，PRIVATE VISUAL RADIO](https://img.yujingblog.top/file/1785749527610_屏幕截图_2026-08-03_173046.webp)

简单一句话介绍：MineRadio 是一个**免费、开源、跨平台**的桌面音乐播放器。它不是那种默认皮肤换颜色的「美化版播放器」，而是把整套播放界面重做了——主视觉、歌词、视觉特效、歌单管理，全给你拎出来重新设计一遍。

## 它长什么样

打开 MineRadio 第一眼，不是播放器，是一个**主页**。

左边是一张每日卡片，会显示日期、热评，还能挂一段 MP4 视频当背景；中间分成六个区块——继续听、音乐库、每日推荐、最近播放、听歌画像、平台推荐；最下面是播放控制条，进度、频谱、播放键、收藏、加心、循环模式、随机播放、桌面歌词开关、画质切换、全屏，全都摆在那一条上。

![MineRadio 主界面：左边每日卡片，右边六大推荐区块，底部播放条](https://img.yujingblog.top/file/1785749499655_image.webp)

这个布局的最大好处是**不用跳来跳去**。以前用某云、某 Q 音乐，每次想换个歌都得点三四下；MineRadio 把「找歌」和「听歌」做成同一个界面，打开就能直接放。

## 真正让我装下去的功能

视觉这块，MineRadio 做了两件事：

**第一，电影镜头级别的粒子/频谱视觉**。它内置了至少七八套预设视觉场景——封面粒子、音域回响（频谱方块）、星河、唱片、星球、滚筒、虚空，每一套都跟着音乐节奏动，重鼓点一来，频谱方块就跟海啸一样往上涌。歌词也是舞台式的，逐行同步高亮，当前那行亮起，其它行慢慢淡掉，跟演唱会字幕一个味儿。

![歌词舞台 + 频谱方块视觉场景](https://img.yujingblog.top/file/1785749054503_屏幕截图_2026-08-03_163140.webp)

**第二，3D 歌单架**。传统歌单是个列表，MineRadio 把它做成了一个可以旋转的 3D 书架，鼠标拖一下就能翻，支持导入多平台收藏歌单、新建分类、批量管理。我自己第一次拖动那一下，确实有点小惊艳。

**第三，桌面模式**。这是个隐藏大杀器——开启后，播放器、主页、歌单全都常驻桌面，你一边写文档、一边刷剧，背景是动态的歌词舞台，控制条在屏幕底端随手就能按。等于把播放器当动态壁纸用，又不只是壁纸。

**第四，自己导入视频当壁纸**。这个我是后来才知道的，菜单里有个「更换 MP4」，把自己下载的视频塞进去，背景立刻换成你想要的画面。上面那张雪景森林就是导入的——不是内置的。

![左侧歌单队列 + 右侧歌词舞台 + 背景导入的雪景壁纸](https://img.yujingblog.top/file/1785749030327_image.webp)

**第五，跨窗口浮动桌面歌词**。这个功能很多人不在意，但用上就回不去——歌词可以置顶到任意窗口上面（视频、办公软件、IDE 全部都行），字体大小、透明度、颜色、位置全部可以拖，**完全不挡你正在做的事**。

还有几个彩蛋我得提一下：摄像头手势控制（隔空操控播放）、360° 自由旋转视角（鼠标拖画面粒子）、网易云/QQ 音乐账号登录（直接同步你已有的歌单和会员音源）。

## 平台覆盖

- **Windows**：主要平台，功能最全
- **macOS**：v1.1.3 起 Intel 和 Apple 芯片合并同一个安装包
- **Android**：移动端可用
- **网页版**：不想装客户端可以直接打开浏览器用

> 网页版不用下载就能体验完整可视化播放效果，跟桌面版功能基本同步。这点对临时想试试、不想装一堆软件的人非常友好。

如果是从 GitHub 上下载，直接去仓库的 **Releases** 页拿对应平台的安装包就行。Windows 是 .exe / .msi，macOS 是 .dmg，Linux 有 .deb / .AppImage。

> macOS 第一次打开如果提示「已损坏」，官方给的解决方案是终端执行 `xattr -cr /Applications/Mineradio.app`，这是因为没走苹果公证的常规操作，不影响安全。

## 一些使用上的小提醒

:::tip[上手建议]
- 默认开起来觉得视觉太炫，可以进设置把「视觉模式」切到「虚空」（无粒子 + 自定义背景），保留播放功能但视觉安静很多
- 想省资源的话把「桌面模式」关掉，常规窗口模式占用小得多
- 网易云和 QQ 音乐登录走的是网页扫码，不会上传你的账号密码到第三方
:::

:::note[关于音源]
MineRadio 本身不存音乐文件，是通过接入网易云、QQ 音乐这些平台来播放。所以你已有的会员账号登录后，能听的就是平台会员曲库；没开会员的话，能听的就是平台免费曲库。这一点跟 LX Music 这种聚合搜索工具不一样，MineRadio 是「播放器 + 视觉」，搜歌 / 找冷门歌不是它的强项。
:::

## 值不值得装

我自己装了一周，已经回不去普通播放器了。具体感受是这样的：

- **如果你只是想安静听歌、不在乎视觉**，MineRadio 不是最优选，原生平台客户端体验更轻
- **如果你喜欢折腾、愿意花十分钟调视觉**，MineRadio 是当前 GitHub 上视觉效果最顶的开源播放器，没有之一
- **如果你想找一个能长期挂着桌面的动态背景 + 播放器二合一**，它几乎是为这个场景量身定做的

总结一句话：免费、开源、无广告、视觉效果拉满、跨平台——这种组合在 2026 年的音乐播放器里真的不多了。喜欢就装来玩玩，反正卸了也就几分钟的事。
