# 我家博客多了一面墙，欢迎来贴便签

博客新开了一面墙，地址 [notes.yujingblog.top](https://notes.yujingblog.top/)，不用登录，谁来了都能贴一张。

内容不限，吐槽、许愿、写诗、出题都行，30 个字以内。贴上去就是一张彩色便签，堆满一整面墙还挺有成就感的。我自己的小愿望是这面墙别变成骂人墙（笑），所以加了字数限制和限流，文明发言哈。

<!-- 在这里插一张便签墙截图，建议 16:9，alt 写上"便签墙主界面" -->

对了，点一下右上角那个「词云图」按钮，能把墙上所有便签做成一张实时词云，谁被提得最多字就最大。现在墙上是空的，谁是第一个字最大的，等你们来定。

## 墙是别人做的，我搬过来的

这面墙不是我自己写的，是 GitHub 上一个叫 **NoteWeb** 的开源项目，作者 **ZyPLJ**，[仓库地址](https://github.com/ZyPLJ/NoteWeb)。

第一次打开作者的在线 demo 我就被惊到了：卡片做成桌面小窗口的样子，红黄绿三个按钮，能拖动、能最大化、能最小化，双击标题栏还能全屏。便利贴做成小窗户，这个脑洞我是服气的。

所以这里得认真谢一下作者：

> ZyPLJ 写了 NoteWeb 还开源出来，MIT 协议随便用，让我这种没服务器、没后端经验的人也能白嫖一面好看的便签墙。**觉得这个项目不错的话，去 [GitHub 仓库](https://github.com/ZyPLJ/NoteWeb) 给它点个 ⭐ Star 呗**，独立开发者写点东西不容易。

::github{repo="ZyPLJ/NoteWeb"}

作者 README 里还留了一串很真实的开发日志：加过 XSS 防护、加过关键词过滤、加过接口限流（"高估互联网的素质了"），最后加了词云图"完结撒花"。一个人把玩具一路修到能抗住全网喷子，挺可以的。

## 上线过程，其实没花一分钱

没买服务器，全靠 Cloudflare 的免费额度（Workers 托管 + D1 数据库，免费层不用绑卡）。大概分三步：

**第一步，前端直接抄**

NoteWeb 的 `wwwroot/` 里就是现成的静态页面，我原封不动搬进 Worker 的静态资源目录，一行前端代码没写。API 按作者后端的返回格式适配了一下（GET 返回字符串数组、POST 返回 `{statusCode, message, data}`），作者的页面拿过来就能跑。

**第二步，数据库和接口**

用 Cloudflare D1（免费的 SQLite 数据库）存便签，写了几个接口：查、贴、删。删便签做了个小设计——**访客点关闭只是临时移除（刷新就回来，跟作者原版一样），我自己这台设备输过管理密码之后，关闭才是真删**，免得墙被路过的人拆了。

**第三步，域名和部署**

给便签墙分了子域名 `notes.yujingblog.top`，顺手把整个域名的 DNS 从阿里云迁到了 Cloudflare（一劳永逸，以后再接 Cloudflare 的东西都方便）。部署用 Wrangler 命令行，一条 `deploy` 完事。

:::note[成本]
托管免费、数据库免费、域名用现有的子域名，总花费：0 元。
:::

## 几个上线后的小细节

- 卡片颜色保持作者原版的浅粉彩，挺耐看
- 便签墙永远刚好一屏，不会出现滚动条
- 词云图作者是用 C# 生成 PNG，我这边换成了 wordcloud2.js 在浏览器里渲染，实测不重叠、有大有小、有横有竖，九成像
- 单 IP 60 秒最多贴 8 张，字数 30 以内

## 写在最后

墙立好了，就差第一张便签。

路过的、常来的、搜到这个页面的，都欢迎去 **[notes.yujingblog.top](https://notes.yujingblog.top/)** 留点什么。想说话不用注册，直接贴墙上，比评论区省事多了。

再谢一次 NoteWeb 的作者，[点个 Star ⭐ 再走](https://github.com/ZyPLJ/NoteWeb)。
