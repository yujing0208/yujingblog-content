# 免费个人图床搭建记：CloudFlare ImgBed + Cloudflare R2

## 为什么突然想搭图床

写博客绕不开一个事：图片放哪。

以前用免费公共图床，心里一直不踏实——要么怕它删图，要么怕它哪天停服跑路。博客里的图要是全裂了，文章基本就废了。也考虑过 GitHub 仓库存图，但国内访问速度一言难尽，还污染提交记录。

所以这次决定：**自己搭一个，一劳永逸。**

## 为什么选 CloudFlare ImgBed

网上图床方案挺多，最后锁定了 [CloudFlare ImgBed](https://github.com/MarSeventh/CloudFlare-ImgBed) 这个开源项目，理由很实在：

- **MIT 开源**，代码全公开，可以放心用
- **Serverless 免费部署**，走 Cloudflare Pages，不用买服务器
- **存储渠道随便选**：R2、Telegram、S3、Discord、HuggingFace、WebDAV 都支持
- **界面现代**：响应式管理界面，支持深色模式、中英文切换
- 有完整的管理后台：上传、目录、标签、批量操作都有

::github{repo="MarSeventh/CloudFlare-ImgBed"}

## 整个方案长这样

```
用户访问 img.yujingblog.top
        ↓
Cloudflare Pages（前端 + API，全球 CDN）
        ↓
KV 数据库（存文件元数据） + R2 存储桶（存图片本体）
```

一句话：**免费额度内全免费**，R2 给 10GB 存储 + 每月 1000 万次读取 + 出站流量不要钱，个人图床用到天荒地老都花不到一分钱。

## 部署过程（照着做就行）

### 第一步：Fork 项目

去 GitHub 把 [CloudFlare-ImgBed](https://github.com/MarSeventh/CloudFlare-ImgBed) 点个 Fork，到自己名下。

### 第二步：Cloudflare Pages 部署

Cloudflare 控制台 → Workers & Pages → 创建应用 → 导入 Git 仓库，选你 Fork 的那个。关键配置别填错：

| 配置项 | 值 |
| --- | --- |
| 构建命令 | `npm install`（v2.0 起改了，不是 npm run build） |
| 构建输出目录 | `/frontend-dist` |

> v2.0 之后构建命令变成 `npm install` 了，网上老教程写的 `npm run build` 是旧版，别照抄。

### 第三步：绑定 KV 数据库

KV 用来存文件元数据，是**必需的**，不绑后端直接罢工。

1. 创建 KV 命名空间，名字随意
2. Pages 项目 → 设置 → 绑定 → 添加 KV 命名空间
3. **变量名必须是 `img_url`**，一字不差，填错进不了管理后台

### 第四步：绑定 R2 存储桶

1. 先开通 R2（这步要绑卡，下面细说）
2. 创建存储桶，位置选**自动**就行，存储类选**标准**
3. Pages 项目 → 设置 → 绑定 → 添加 R2 存储桶
4. **变量名必须是 `img_r2`**

### 第五步：绑定自定义域名

部署完你会得到一个 `xxx.pages.dev` 的地址，但**这个域名国内访问不稳定**，必须绑自己的域名。

我在阿里云 DNS 给 `yujingblog.top` 加了一条 CNAME 记录，指向 pages.dev 地址，然后在 Pages 项目里添加自定义域 `img.yujingblog.top`，等 SSL 证书签发完就能用了。

### 第六步：进管理后台配置

访问 `https://img.yujingblog.top/dashboard`：

1. **立刻设置管理员密码**（默认无密码，谁都能进，很危险）
2. 系统设置 → 上传设置 → 添加 R2 渠道并启用

完事，上传一张图测试，能出链接就成功了。

## 踩过的坑（血泪教训）

### 开通 R2 要绑卡，但不会扣钱

R2 虽然免费额度很大，但 Cloudflare 要求**必须绑定支付方式才能激活**。当时卡在这一步卡了半天，网上教程说得不清不楚，直到看了羊角快车的这篇博客才搞定：

[Cloudflare R2 使用指南：零成本管理博客媒体文件](https://www.cnblogs.com/pc2005/p/20537229)

几个关键点，都是那篇博客教的：

- **银联卡就行**，不一定要 Visa / MasterCard，卡面有银联标志即可
- 安全码是卡片**背面签名条末端的 3 位数字**，不是卡号末尾 3 位
- 国内卡填完会触发**短信验证码**，收到输入就激活了
- 只是验证身份，**免费额度内不会扣费**，用了几个月账单一直是 $0.00

> 特别感谢羊角快车的这篇博客，没有它我可能就卡在绑卡这步放弃了。

### pages.dev 域名国内打不开

部署完先用 pages.dev 测，结果时好时坏，加载慢还偶尔白屏。**必须绑自定义域名**，绑完 `img.yujingblog.top` 之后速度立刻正常了。

### R2 想绑自定义域名？没戏

R2 存储桶设置里有个自定义域名功能，但要求**域名必须完整托管在 Cloudflare**（DNS 服务器迁过去）。我的域名在阿里云，只做了 CNAME 部分接入，所以用不了。

好在**图床本身不需要**——图片访问走 Pages 自定义域名代理，链接照样是 `img.yujingblog.top/file/xxx`，体验没差别。

### 页面黑屏？八成是 KV 没绑定

有次部署完打开网站黑屏，排查半天：前端 HTML、JS、CSS 全正常，但 `/api/*` 接口全部返回 HTML 而不是 JSON。原因就是 **KV 数据库没绑定，或者绑定了没重新部署**。绑定完去部署页面点「重试部署」就好了。
