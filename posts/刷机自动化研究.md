# 刷机自动化研究
# 前言
具体刷机教程见[这里](https://www.yujingblog.top/刷机教程/)
## 刷机脚本展示

> [!NOTE] 来源
> 此为蓝色大肥鱼出品

### 解BL锁
```
@echo off
title Auto Flash Script (Unisoc)

echo ========================================
echo  Please connect tablet in BROM mode:
echo  1. Power off tablet
echo  2. Press and hold VOLUME DOWN
echo  3. Connect USB cable
echo ========================================
pause

echo Waiting for device connection (300s)...
spd_dump --wait 300 fdl fdl1.bin 0x5500 fdl fdl2.bin 0x9efffe00 exec w uboot uboot_c8hpro_unlock.bin w splloader splloader_c8hpro_disverify.bin e userdata reset

echo ========================================
echo  Flash completed. Tablet will reboot.
echo  If not, manually power on.
echo ========================================
pause
```
### 刷入GSI
```
@echo off
title Flash System Image

echo ========================================
echo  Flash system.img to tablet
echo  Ensure system.img is in current folder
echo  Connect tablet in BROM mode:
echo  1. Power off tablet
echo  2. Press and hold VOLUME DOWN
echo  3. Connect USB cable
echo ========================================
pause

spd_dump --wait 300 fdl fdl1.bin 0x5500 fdl fdl2.bin 0x9efffe00 exec w system system.img e userdata reset

echo ========================================
echo  Flash completed. Tablet will reboot.
echo  If not, manually power on.
echo ========================================
pause
```
### 回锁恢复原系统
```
@echo off
title Full Recovery Flash

echo ========================================
echo  Full recovery flash (boot + system + vendor + vbmeta + misc + miscdata)
echo  Ensure all required .bin files are in current folder:
echo    boot.bin, system.bin, vendor.bin, vbmeta.bin, misc.bin, miscdata.bin
echo  Connect tablet in BROM mode:
echo  1. Power off tablet
echo  2. Press and hold VOLUME DOWN
echo  3. Connect USB cable
echo ========================================
pause

spd_dump --wait 300 fdl fdl1.bin 0x5500 fdl fdl2.bin 0x9efffe00 exec w boot boot.bin w system system.bin w vendor vendor.bin w vbmeta vbmeta.bin w misc misc.bin w miscdata miscdata.bin e userdata reset

echo ========================================
echo  Full recovery flash completed. Tablet will reboot.
echo  If not, manually power on.
echo ========================================
pause
```
## 使用方法
### 先将代码保存为.bat
1. 新建文本文档
2. 将代码复制进去
3. 并将后缀改为.bat
### 放到正确位置
都应放到==spd_dump.exe所在目录==，所在目录中须要刷入的文件
#### 解锁和刷入脚本(前两个)
要有
- fdl1.bin
- fdl2.bin
- uboot_c8hpro_unlock.bin
- splloader_c8hpro_disverify.bin
- system.img
#### 回锁恢复(最后一个)
要有
- fdl1.bin
- fdl2.bin
- boot.bin
- system.bin
- vendor.bin
- vbmeta.bin
- misc.bin
- miscdata.bin
### 设备关机后，按顺序点击脚本即可
