# 刷机自动化脚本上线记

:::tip[只想学「怎么刷」？]
那你不用在这儿听我絮叨了——**直接跳到文末的[使用说明](#使用说明)**，从下载、解压到刷完回锁，一步一步都写全了，照着点就行。

想省事的直接下百度网盘那份整包：**解压出来就能双击脚本开跑**，不用自己摆目录，也不用自己备份原厂镜像。
:::

先交代来龙去脉，不然容易看懵。

最早我写过一篇[科大讯飞 c8hPro 学生机刷机教程](/刷机教程/)，把整套流程一步步拆开讲——打开深刷工具、进 BROM 模式、一条一条粘贴命令，从解 BL 锁到刷 GSI 再到回锁。那篇是纯手动的，照着做能成，但命令多、容易粘错。

后来我把那些命令整理成了三个脚本：

[[刷机自动化研究]]

但那版说实话挺糙的。文章结尾我自己写着「之后会在 github 上发布下载直用脚本」——这话欠了快一个月，今天把它还上。

## 上一版到底糙在哪

翻回去看那三个脚本，大概长这样：

```bat
@echo off
title Auto Flash Script (Unisoc)

echo ========================================
echo  Please connect tablet in BROM mode:
echo  1. Power off tablet
echo  2. Press and hold VOLUME DOWN
echo  3. Connect USB cable
echo ========================================
pause
```

问题挺多：

- **提示全是英文**。「Press and hold VOLUME DOWN」第一次刷机的人得对着翻译看，还不一定知道要「按住不放」而不是「按一下」。
- **得手动存成 bat**。文章里写的是「新建文本文档 → 粘贴代码 → 把后缀改成 .bat」，多一步不说，Windows 默认还藏后缀名，改半天改不动。
- **驱动要自己先装**。没装驱动的话脚本压根连不上设备，只会甩你一个看不懂的报错，然后就没有然后了。
- **路径写死**。`spd_dump.exe`、`fdl1.bin`、`system.img` 必须和脚本躺在同一个目录里，放错一层就找不到文件。
- **回锁那步是半截的**。第三个脚本虽然写了回锁，但原教程里第三章本身就是「代码此处不再赘述」。

## 这次改了什么

| | 上一版 | 这一版 |
| --- | --- | --- |
| 提示语言 | 英文 | **全程中文**，每一步都告诉你该干什么 |
| 获取方式 | 手动新建 txt 改后缀 | 直接从仓库下载，双击就能跑 |
| 驱动 | 自己先装 | **自动检测，缺了就静默安装**，需要管理员权限会自己弹 UAC |
| 路径 | 写死，必须放对位置 | **全相对路径**，整个文件夹拷到哪都能跑 |
| 依赖检查 | 无 | 刷写前逐个校验必需文件，缺哪个直接报名字 |
| 回锁恢复 | 「此处不再赘述」 | 完整的回锁 + 恢复原厂脚本 |
| 结构 | 三个平铺的 bat | 收进 `刷机自动化脚本\`，和程序、镜像分层清楚 |

驱动那块是我最想改的。原来你得先去装紫光展锐驱动，装完才轮到脚本登场；现在是脚本自己判断——检测到驱动就直接跳过，没检测到就调用驱动包里的 `DPInst64.exe` 静默安装（顺便还用 `dpinst.xml` 把 `sprdadc`、`sprdvcom`、`sprdvmdm`、`rdavcom` 四个驱动一起装上），装完再往下走。

## 三个脚本的分工

| 脚本 | 作用 | 对应教程章节 |
| --- | --- | --- |
| `1-解锁BL.bat` | 解锁 Bootloader | 一、解除 BL 锁 |
| `2-刷入GSI.bat` | 刷入第三方系统镜像 | 二、刷写 GSI |
| `3-回锁恢复.bat` | 回锁并恢复原厂系统 | 三、刷回原系统与回锁 |

等待设备那段也重写了。原来只有三行英文，现在会明确告诉你：

```
  [3/3] 等待设备接入（进入 BROM 模式）

        1. 先把平板【关机】
        2. 长按【音量减】键不要松手
        3. 保持按住，把 USB 数据线插入电脑

        识别到设备后会自动开始，最长等待 300 秒。
        等待期间请不要松手、不要拔线。
```

因为 `spd_dump` 一旦开始等设备，就会接管屏幕刷它自己的英文日志，中文提示会被顶上去、滚掉。所以除了启动前的横幅，还顺手把**窗口标题栏**也改成了「等待设备中 - 请长按音量减键并插入数据线」——标题栏是唯一不会被它刷掉的位置。

## 顺带踩的一个坑：编码

脚本里的中文提示要正常显示，文件必须是 **GBK（936）编码**，因为 cmd 是按 GBK 解码批处理文件的。

那能不能干脆用 UTF-8，然后在开头 `chcp 65001` 切代码页？我实测了，**不行**。

同一份内容存成 UTF-8，开头加 `chcp 65001`，跑下来大部分中文确实正常，但其中一行直接崩了：

```
'�接入（进入' is not recognized as an internal or external command
```

原因是 cmd 在 65001 代码页下读取批处理文件时，行缓冲还是按字节切的，多字节的 UTF-8 汉字一旦跨过缓冲边界，整行解析就错位了。所以这条路是赌运气，不能用在刷机这种一步错就得重来的场景。

结论：老老实实用 GBK。也因此，这些 `.bat` 在 GitHub 网页上预览时中文是乱码的——**这是正常的**，下载到本地用记事本或 VSCode 选 GBK 打开就正常了，别手贱把它转成 UTF-8。

## 使用说明

整个流程说白了就一句话：**把文件摆对，然后按顺序双击三个脚本**。脚本窗口大概长这样：

![刷机脚本运行窗口示例 w-80%](https://img.yujingblog.top/file/1790321850518_image.png "窗口里每一步在干什么都写着中文，跟着提示走就行")

### 开工前先凑齐这几样

| 需要什么 | 说明 |
| --- | --- |
| 一台 Windows 电脑 | Win7 / 10 / 11 都行 |
| **一根能传数据的 USB 线** | 最容易翻车的一条。很多线只焊了电源，插上只充电、不认设备，务必用原装线或确定能传文件的线 |
| 平板留点电（30% 以上更稳） | 深刷不吃系统、靠 USB 供电就能跑，电量低甚至亏电一般也能进 BROM；但写 eMMC 那几分钟电流会拉高，电量太低容易中途掉线——那才是最危险的时候 |
| `Auto-flash` 文件夹 | 见上面的[下载地址](#下载地址)。**网盘那份下载解压就能直接双击脚本**，不用自己拼 |
| 原厂镜像（回锁用） | **网盘整包里已经带上了**，不用自己备份。只有从 GitHub 仓库拿的人需要自己准备 |

### 第一步：把文件摆对

解压出来的目录必须长这样，**层级一个字都不能改**（网盘包里已经是这个样子了，解压完直接用）：

```
Auto-flash\
├── Driver_R4.21.3201\
│   └── Driver_R4.21.3201\DriversForWin10\   ← 展锐驱动
└── spd_dump_stable_250131\
    ├── SPRD\
    │   ├── spd_dump.exe                     ← 深刷工具
    │   └── _file\                           ← 所有镜像都放这儿
    │       ├── fdl1.bin  fdl2.bin
    │       ├── uboot_c8hpro_unlock.bin      ← 解锁用
    │       ├── splloader_c8hpro_disverify.bin
    │       ├── uboot.bin  splloader.bin     ← 原厂引导（回锁用）
    │       ├── boot.bin  system.bin  vendor.bin
    │       ├── vbmeta.bin  misc.bin  miscdata.bin
    │       └── system.img                   ← 要刷的 GSI
    └── 刷机自动化脚本\
        ├── 1-解锁BL.bat
        ├── 2-刷入GSI.bat
        └── 3-回锁恢复.bat
```

`Auto-flash` 这个外层文件夹**可以随便挪**（D 盘、桌面、U 盘都行），但里面几层的相对位置不能动——脚本全靠相对路径找程序和镜像。所以也**别把 `.bat` 单独拖出来双击**，那样一定报「找不到 spd_dump.exe」。

### 第二步：解锁 BL——双击 `1-解锁BL.bat`

1. 先让平板**彻底关机**。不是息屏、不是休眠，长按电源键 15 秒强制断电最保险。
2. 双击 `1-解锁BL.bat`，会弹「用户账户控制」，点**是**（装驱动需要管理员权限）。
3. 剩下的脚本自己跑，你只管看：
   - `[1/3]` 检查展锐驱动。没装就自动静默安装，大概 10~30 秒，装完会告诉你。
   - `[2/3]` 逐个核对解锁要用的文件，缺哪个直接报名字。
   - `[3/3]` 提示你进 BROM 模式。
4. 看到第 3 步的提示后按任意键，然后**赶紧做这套动作**：

   > **按住音量减键不要松手** → 保持按住 → 把 USB 线插进电脑。

   注意是「**按住不放**」而不是「按一下」，新手基本都卡在这儿。插上之后窗口标题会变成「等待设备中 - 请长按音量减键并插入数据线」，这**是正常的**——`spd_dump` 一开始等设备就会接管屏幕刷它自己的英文日志，把中文提示顶掉，所以我把提示挪到标题栏去了。最长等 300 秒。
5. 识别到设备就开始写入，写完平板自动重启。开机时看到解锁警告 → 成了，接着走第三步。

### 第三步：刷 GSI——双击 `2-刷入GSI.bat`

流程和上一步一模一样：关机 → 双击 → 提示进 BROM 时按住音量减插线。

只有一处不同：`system.img` 差不多 3 GB，写入要 **1~3 分钟**，这段时间**千万别拔线**。刷完会清 userdata 并自动重启，**首次开机可能要好几分钟**，黑屏久一点别慌。

### 第四步：想回原厂——双击 `3-回锁恢复.bat`

会把 bootloader 重新上锁，并把原厂镜像写回去。脚本先让你输入 `Y` 回车确认，打别的键就直接取消、不做任何写入。确认后它一次写回 uboot、splloader、boot、system、vendor、vbmeta、misc、miscdata 八个分区再上锁，**约 3~6 分钟**。

网盘整包里那份原厂镜像，就是我从这台 C8hPro 上备份下来的，脚本要用的文件名一个不差。**解压出来直接点脚本就能刷回原厂、把锁重新上回去，不用自己备份全盘。** 前提是别去改动 `_file\` 里原来那些文件。

### 卡住了？对着这张表查

| 现象 | 八成是 | 怎么办 |
| --- | --- | --- |
| 一直「正在等待设备连接」，等到超时 | 没进 BROM / 线不传数据 / 驱动没装上 | 依次查：① 平板是不是真关机了 ② 音量减是不是**一直按着** ③ 换一根能传数据的线 ④ 重跑 `1-解锁BL.bat` 装驱动 |
| 报「找不到 spd_dump.exe」 | 脚本被单独拿出来了 | 用完整的 `Auto-flash` 文件夹，别只拖 `.bat` |
| 报「缺少 xxx.bin」 | 镜像没放对位置 | 全部镜像丢进 `spd_dump_stable_250131\SPRD\_file\` |
| 驱动装不上 | 没拿到管理员权限 | 右键 `.bat` →「以管理员身份运行」 |
| 平板黑屏 / 无限重启 | 刷写中断或镜像不匹配 | 长按**音量减 + 电源键 15 秒**强制断电，再重来 |
| 中文提示全是乱码 | 文件编码被改成 UTF-8 了 | 重新下载，别用编辑器转存编码 |
| 双击窗口一闪就没 | 基本是文件缺失 | 往上翻窗口里的提示，回到上面几行对号入座 |

### 还得多说一句

刷机**会清空全部数据**，而且有风险。备份（原教程那条 `r all`）必须先做；如果这台平板是课堂版、平时还要用来上课，建议别折腾。
