# 我家博客多了张地图，标我去过哪儿了

博客新开了一页 [足迹地图](https://yujingblog.top/footprint/)：一张高德地图，把我去过的地方一个个标出来，去过的省份会整块被点亮。现在上面孤零零只有一个点——合肥，因为数据我才刚清空，打算一个个慢慢攒，先从自己家门口开始（笑）。

<!-- 在这里插一张足迹页面截图，建议 16:9，alt 写上"足迹地图主界面，合肥被点亮" -->

打开页面浏览器会问你要不要允许定位，点允许，地图会自己缩到你当前所在的城市，再打个蓝点标上「我的位置」。右下角那个定位按钮随时能重新定位。

## 这地图也是别人做的，我搬过来改的

不是我自己写的地图引擎，是 GitHub 上一个叫 **XiaoTen-FootprintMap** 的开源项目，作者 **Jiosanity**，地图用的是高德 Web 端 JS API。

第一次在作者仓库里看到效果图我就想要——能把「去过哪些省」做成一张被点亮的地图，比干巴巴列清单有意思多了。所以认真谢一下作者：

> Jiosanity 写了 XiaoTen-FootprintMap 还开源出来，让我这种前端只会复制粘贴的人也能白嫖一张好看的足迹地图。**觉得这个项目不错的话，去 [GitHub 仓库](https://github.com/Jiosanity/XiaoTen-FootprintMap) 点个 ⭐ Star 呗**。

::github{repo="Jiosanity/XiaoTen-FootprintMap"}

## 它都能干啥

- **省份 / 国家高亮**：去过的省份整块亮起来，一眼看出自己在国内走到哪了
- **城市标记**：每个去过的地方一个标记，点开有照片轮播、简介、链接
- **分类筛选**：左上角可以按「去过 / 年份 / 城市 / 美食」之类筛，只显示某一类
- **自动定位**：加载就定位到你当前位置，打个蓝点，出门在外也能看自己在哪
- **暗色适配**：跟着博客主题走，晚上看不瞎眼

## 怎么搭起来的，也没花一分钱

组件是纯前端的 vanilla JS，我把它整个塞进博客的 `public/footprint/` 目录，再用一个 Astro 页面包一层壳子，挂到导航栏「我的」下面。

**数据我自己留了个后门**：足迹点不写死在前端，而是放在我博客的内容仓库里（用 Obsidian 维护的 `data/footprints.ts`）。所以以后想加个地点，不用动代码，改一下这个文件、推一下内容仓库，地图自动就更新了。格式也简单，填个城市名加经纬度就行，经纬度在高德坐标拾取器点一下就能拿到。

:::note[关于安全]
网页地图的 Key 本来就暴露在前端、谁都能在源码里看到——但这不是漏洞，高德这类 JS API 都这样。真正拦住滥用的是**域名白名单**：我在控制台把 Key 锁死成 `yujingblog.top` 和 `localhost`，别人抄走也调不了。所以放心用。
:::

**成本**：高德个人开发者免费、Vercel 托管免费，总花费 0 元，跟便签墙一个路数。

## 写在最后

现在地图上只有合肥一个点，挺寒酸的。但这是个开始，以后去哪儿玩了就顺手记一笔，攒个三五年，这张地图应该会好看不少。

路过的朋友欢迎去 [足迹地图](https://yujingblog.top/footprint/) 看看，也欢迎在评论区告诉我你地图上有什么——毕竟，比起「去过哪」，我更想知道「还该去哪」。
